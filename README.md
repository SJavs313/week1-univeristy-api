week1 homework api using FastApi

to install requirments in your command line terminal run the following: 'python -m pip install -r requirements.txt'.

run the server: uvicorn main:app --reload

open these URLs in your browser:
http://127.0.0.1:8000/
http://127.0.0.1:8000/students/
http://127.0.0.1:8000/students/s1
http://127.0.0.1:8000/students/s10
